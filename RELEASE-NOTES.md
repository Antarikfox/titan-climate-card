# TITAN HATCH v1.0.0

First public release of the TITAN climate card for Home Assistant.

- Matte white MECHA housing with frosted armor and embedded artwork.
- Temperature and humidity readouts with two smooth 24-hour history graphs.
- Transparent background with configurable background and housing opacity.
- Gentle, staggered LED blinking, brightness controls and reduced-motion support.
- Visual configuration editor and optional battery indicator.
- Graceful handling of unavailable sensors and missing Recorder history.
- Standalone interactive demo with clearly marked synthetic data.

The code and mocked Home Assistant integration were tested in a browser. Performance on individual tablets and installation on a real Home Assistant instance have not yet been verified.

Install the repository as a custom Dashboard repository in HACS. It has not yet been accepted into the default catalog.
