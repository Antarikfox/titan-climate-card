# TITAN HATCH v1.0.1

## Русский

- Обновлена страница HACS: полное описание на русском и английском.
- Добавлено превью с демонстрационными показаниями температуры, влажности и графиками за сутки.
- Установка через поиск HACS описана как основной способ; пользовательский репозиторий оставлен запасным.
- Добавлены полные английские инструкции, порядок обновления и перехода с ручной установки.

Это выпуск документации. JavaScript карточки и её поведение не изменены.
После обновления карточки до v1.0.1 закрой и снова открой её страницу в HACS.

## English

- Updated the HACS overview with full Russian and English documentation.
- Added a preview with simulated temperature, humidity and 24-hour history graphs.
- Made HACS search the primary installation method, retaining custom repositories as a fallback.
- Added full English guides, update instructions and manual-to-HACS migration steps.

This is a documentation release. The card JavaScript and runtime behavior are unchanged.
After updating the card to v1.0.1, close and reopen its HACS repository page.

Available in the default HACS catalog as **TITAN HATCH Climate Card**.
